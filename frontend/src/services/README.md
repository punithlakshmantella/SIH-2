# Frontend Layouts, Services, Hooks, Store, Types
- `layouts/`: App layout, sidebar, header, RBAC wrappers.
- `services/`: API clients for auth, cameras, anpr, vehicles, trajectory, analytics, alerts.
- `hooks/`: Custom react hooks (useWebSocket, useDebounce, useMap).
- `store/`: Zustand stores for global auth, map state, live detection stream.
- `types/`: TypeScript type definitions matching backend Pydantic schemas.
